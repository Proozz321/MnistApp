# MnistApp

Reconhecimento de dígitos manuscritos utilizando o dataset MNIST.

## Tecnologias
- C# / .NET
- ML.NET
- Avalonia UI

## Estrutura
- `src/` — Código fonte
- `models/` — Modelo treinado
- `datasets/` — Dataset MNIST
- `docs/` — Documentação
- `scripts/` — Scripts auxiliares

## Como correr
cd src/MnistApp.App
dotnet run
